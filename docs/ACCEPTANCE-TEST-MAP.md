# Feature-to-acceptance-test map

Every shipped roadmap feature has one stable `F-NN` identifier, a measurable outcome, executable
evidence, review evidence, and at least one top-level ISO/IEC 25010:2023 product-quality
characteristic. Test anchors use `path::test_symbol` for Python and `path::test title` for
JavaScript. `scripts/acceptance_map_check.py` resolves every path and symbol, enforces the exact 2023
vocabulary, validates the row schema, and requires one-to-one coverage of the shipped inventory in
[`ROADMAP.md`](ROADMAP.md).

Owner: maintainer. A feature is not done until its roadmap inventory row, acceptance row, and tests
change together.
