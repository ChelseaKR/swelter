# Legacy architecture-decision paths

This directory preserves the original architecture-decision files so historical review links and
bookmarks continue to resolve. The standards-compliant source of record is now
[`docs/adr/`](../adr/README.md); new decisions and new links belong there.

The original log assigned ADR 0013 twice. In the authoritative log, the accumulation/cache decision
remains ADR 0013 and the context-layer overlay is ADR 0023. The original text remains here as
historical evidence; small banners route readers to the current number and amended licensing record.
